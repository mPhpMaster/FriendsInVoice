# 🎧 FriendsInVoice — إضافة لـ Vencord

**[English](README.md)**

بتشوف بنظرة وحدة **أصحابك بأي روم صوتي، مين معهم، وبتدخل الروم بضغطة وحدة** — من صفحة كاملة جوّا ديسكورد.

## شو بتعمل

- **زر 🎧 بقائمة السيرفرات** عليه رقم مباشر بعدد أصحابك اللي بروم صوتي هلق (بيصير أصفر وبيعدّ بس ناس **قائمتي** لما تضيف حدا).
- **صفحة كاملة مش نافذة صغيرة** — بتغطي المساحة الرئيسية جنب قائمة السيرفرات. بتتسكّر بـ ✕ أو `Esc` أو بالضغط على أي سيرفر.
- **تبويب All rooms (كل الرومات)** — كل روم صوتي فيه صاحب واحد على الأقل، مرتبين جنب بعض:
  - اسم السيرفر وصورته، اسم الروم (اضغط عليه بيفتحلك القناة)،
  - **"Here because of:"** — الأصحاب اللي بسببهم الروم طالع، فبتعرف فوراً ليش الروم موجود،
  - كل الموجودين بالروم مع علامات `FRIEND` / `MY LIST` / `LIVE` وأيقونات المايك والسماعة المسكّرة،
  - زر **Join** (بيصير `Joined` إذا إنت أصلاً جوّا، و`Locked` إذا ما عندك صلاحية).
- **تبويب ⭐ My list (قائمتي)** — بتختار ناس معينين تتابعهم. كل واحد إله كرت بيبيّن وين هو، مين معه، وزر دخول — أو "مش بروم صوتي بتقدر تشوفه".
  - بتضيف حدا بكتابة اسمه بالخانة فوق التبويب،
  - أو بتمرّر الماوس على أي حدا بروم وبتضغط **☆**،
  - أو **كليك يمين على أي مستخدم ← Add to My list (Friends in Voice)** (بتشتغل حتى لو مش صاحبك).
  - وبتشيله بالضغط على **★** الصفرا.
- بحث بالأسماء والسيرفرات والرومات.
- كل شي بيتحدّث لحاله لما حدا يدخل أو يطلع أو يسكّر المايك أو يبلّش بث.
- المكالمات الخاصة والجماعية كمان بتطلع.

## التركيب

الإضافات الخاصة بتحتاج Vencord مبني من السورس. المثبّت المرفق بيعمل كل شي عنك (ويندوز):

1. [نزّل آخر إصدار](../../releases/latest) وفك الضغط.
2. دبل كليك على **`install.bat`**. بيركّب Git / Node.js / pnpm إذا ناقصين، بينزّل Vencord، بيضيف الإضافة، بيبنيها، وبيركّبها على ديسكورد.
3. سكّر ديسكورد بالكامل (أيقونته جنب الساعة ← **Quit**) وافتحه من جديد.
4. **Settings ← Vencord ← Plugins**، ابحث عن **FriendsInVoice** وفعّلها.

عندك مجلد Vencord سورس من قبل؟ شغّل:

```powershell
.\install.ps1 -VencordDir D:\Vencord
```

## ملاحظات وحدود

- **ديسكورد ما بيبعت معلومات الصوت إلا للسيرفرات اللي إنت كمان فيها** (والمكالمات اللي بتقدر تشوفها). صاحبك إذا بروم بسيرفر إنت مش فيه ما رح يطلع — هاد قيد من ديسكورد نفسه وما في إضافة بتقدر تتجاوزه.
- الصفحة مرسومة فوق المساحة الرئيسية لديسكورد (ديسكورد ما فيه طريقة رسمية لإضافة صفحات). إذا الزر ما طلع بعد ما فعّلت الإضافة، اضغط على أي سيرفر مرة أو اعمل `Ctrl+R`.
- إذا تحديث ديسكورد شال Vencord، شغّل `install.bat` مرة ثانية.
- **قائمتي** محفوظة بإعدادات Vencord، فبتضل بعد إعادة التشغيل.
