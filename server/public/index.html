🔊 Friends in Voice

صفحة تشوف فيها أصحابك بأي روم صوتي ومين معهم، وتدخل عندهم بضغطة. فيها كمان تنبيهات، وقائمة Run away، وسجل، والحرّاس الشخصيين.

Windows (Vencord)

نزّل المثبّت وافتحه. هو يجيب آخر إصدار، ويثبّت Vencord إذا ما كان عندك، ويضيف الإضافة.

⬇️ تحميل المثبّت (Windows)

أو الصق هذا الأمر في PowerShell:

irm https://friendsinvoice.sarhsoft.com/install.ps1 | iex

Windows ممكن يحذّرك لأن الملف غير موقّع: اضغط «More info» ثم «Run anyway».

macOS و Linux (Vencord)

افتح Terminal والصق:

curl -fsSL https://friendsinvoice.sarhsoft.com/install.sh | bash

BetterDiscord

نزّل ملف الإضافة وحطه في مجلد الإضافات حق BetterDiscord، وبعدين فعّلها.

⬇️ FriendsInVoice.plugin.js

الأمان

  • الإضافة ما تسوي أي طلبات لديسكورد بالخلفية.
  • الحرّاس الشخصيين يتربطون بكود، والأوامر مشفّرة من طرف لطرف عبر هذا السيرفر. ما ينرسل أي توكن ديسكورد.
  • المثبّت ينزّل الإصدار من صفحة الإصدارات في GitHub، والكود كله مفتوح.
