🔊 Friends in Voice

A page that shows which voice rooms your friends are in and who's with them, with one-click join. It also has alerts, a Run away list, a Log and Personal Guards.

Windows (Vencord)

Download the installer and open it. It gets the newest release, installs Vencord if you don't have it, and adds the plugin.

⬇️ Download the installer (Windows)

Or paste this in PowerShell:

irm https://friendsinvoice.sarhsoft.com/install.ps1 | iex

Windows may warn you because the file isn't signed: click "More info", then "Run anyway".

macOS and Linux (Vencord)

Open Terminal and paste:

curl -fsSL https://friendsinvoice.sarhsoft.com/install.sh | bash

BetterDiscord

Download the plugin file, put it in BetterDiscord's plugins folder, then enable it.

⬇️ FriendsInVoice.plugin.js

Safety

  • The plugin makes no Discord requests in the background.
  • Personal Guards pair with a code, and commands are end-to-end encrypted through this server. No Discord token is ever sent.
  • The installer downloads the release from GitHub releases, and all the code is open.
